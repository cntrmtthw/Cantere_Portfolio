# Jomar Matthew B. Cantere | Online Portfolio

A black and white, single-page portfolio. Plain HTML and CSS, no build step, no icons.

Live site (after Pages is enabled): https://cntrmtthw.github.io/Cantere_Portfolio/

## Files

- `index.html` is the whole site (text, styles, and script).
- `images/profile.png` is the portrait.
- `images/` also holds the cropped achievement images and `achievements-all.png`.

## Publish on GitHub Pages

1. Open https://github.com/cntrmtthw/Cantere_Portfolio and choose **Add file > Upload files**.
2. Drag in `index.html`, `README.md`, and the whole `images` folder, then commit.
3. Go to **Settings > Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait a minute or two, then open the live link above.

## Edit

- Achievements: edit the `A` array in the script at the bottom of `index.html`, and add the matching image in `images/`.
- Colors: change `--ink` and `--paper` at the top of the stylesheet.
